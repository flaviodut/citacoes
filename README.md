# 🎭 Citações

> "As melhores frases soltas dos personagens que marcam o dia-a-dia da empresa."

Este projeto nasceu de uma missão nobre: preservar para a posteridade as pérolas de sabedoria (e absurdos) que meus ex-colegas de trabalho soltaram ao longo dos anos. Algumas frases são tão memoráveis que merecem ser eternizadas.

## 🎯 O que é?

Uma coleção de citações épicas ditas por coworkers que, por algum motivo, ficaram gravadas na memória. Clique em "Ver outra" para descobrir novas pérolas, ou "Ver todas" para ver o acervo completo.

## 😂 Por que?

Porque às vezes o trabalho é tão surreal que a única coisa que nos resta é rir das coisas que ouvimos. E porque memórias coletivas merecem ser documentadas.

## 🚀 Como usar

Basta abrir o site e se divertir. É simples assim.
